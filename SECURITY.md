# Security

InkPy is experimental firmware for Xteink X4 Pro. Only the latest release is
maintained; there is no promise of a security update schedule.

Python scripts are not sandboxed. They can modify SD files and use networking.
Do not run untrusted scripts, and keep API keys and Wi-Fi passwords out of Git,
issue reports, and shared SD images. Document parsers are not a security boundary.

If GitHub's private vulnerability reporting is available on this repository,
use **Security → Report a vulnerability**. Otherwise contact the maintainer
through their [GitHub profile](https://github.com/cSohaib) to arrange a private
report. Do not publish exploit details or credentials in a public issue.

Include the firmware release, device model, steps to reproduce, and a minimal
sample without personal data. Ordinary rendering bugs can use public issues.
